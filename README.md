# To-Do List (CLI)
A simple command-line to-do list application built in Python. Allows users to add, view, remove, and mark tasks as completed — all through a terminal-based menu.

## Features

- Add new tasks
- View all tasks
- Remove a task
- Mark a task as completed
- Exit the application

## Technologies

- Python 3

## How to Run

1. Clone the repository:
```bash
   git clone https://github.com/asanovamoldir-09/to-do_list.git
```
2. Navigate to the project folder:
```bash
   cd to-do_list
```
3. Run the script:
```bash
   python main.py
```
